#little-scale-ableton-sdk-extensions

reconstruct: select multiple clips. reconstruction of the longest clip will be attempted by using only snippets from the shorter clips
slice-at-transients: with gate, hold and fade
sort-by: select multiple clips and re-order based on various categories of frequency and time domain analysis 
sort-frames: select a single clip and re-order FFT frames based on various categories of frequency and time domain analysis
